# Damien — Adaptive AI Assistant

Web-based personal assistant with:

1. **Adaptive learning** — tone, brevity, and interests learned from conversation and stored per account  
2. **Offline** — service worker + local core chat, devices, and generation  
3. **Universal login** — Gmail, Apple, or Microsoft (demo sign-in)  
4. **Cross-device sync** — profile keyed by email in local cloud store  
5. **Broad assistance** — chat with a friendly, dynamic personality  
6. **Device control** — open/close any registered device (and via chat)  
7. **Image & video generation** — prompt-driven canvas stills and short WebM clips  
8. **Web access** — responsive PWA UI  
9. **Voice recognition** — Web Speech API enrollment and unlock  

```bash
npm install
npm run dev
```
